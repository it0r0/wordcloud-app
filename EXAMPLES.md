## Tips for Different Purposes

### For Marketing/Branding
- **Priority Words**: 3-5 key brand values
- **Regular Words**: Product features, benefits, differentiators
- **Font Size Range**: Wide (10-200) for dramatic effect
- **Color Scheme**: Match brand colors or use professional schemes (viridis, twilight)

### For Events/Celebrations
- **Priority Words**: Event name, year, main theme
- **Regular Words**: Activities, features, guest names
- **Font Size Range**: Very wide (20-250) for impact
- **Color Scheme**: Vibrant (rainbow, turbo, jet)
- **Orientation**: All horizontal for readability

### For Education
- **Priority Words**: Key concepts, main topics
- **Regular Words**: Related terms, examples, definitions
- **Font Size Range**: Moderate (15-100) for balance
- **Color Scheme**: Professional (cividis, viridis)

### For Personal Projects
- **Priority Words**: Names, dates, special words
- **Regular Words**: Memories, feelings, descriptions
- **Font Size Range**: Based on preference
- **Color Scheme**: Match theme or mood
- **Silhouette**: Custom shapes (hearts, stars, initials)

## Color Scheme Guide

- **viridis**: Professional, scientific, great readability
- **plasma**: Modern, energetic, good contrast
- **inferno**: Warm, intense, eye-catching
- **magma**: Bold, dramatic, strong presence
- **twilight**: Elegant, subtle, sophisticated
- **rainbow**: Colorful, playful, diverse
- **turbo**: Bright, vibrant, high energy
- **jet**: Classic, strong contrast

## Common Mistakes to Avoid

1. ❌ **Too many priority words** → Makes them less special
   ✅ Keep it to 3-7 priority words max

2. ❌ **Font size range too narrow** → All words look same size
   ✅ Use at least 3:1 ratio (e.g., 10-30 or 20-100)

3. ❌ **Too many words** → Cluttered, unreadable
   ✅ Limit to 50-200 words depending on canvas size

4. ❌ **Low contrast colors on light background** → Hard to read
   ✅ Use dark/vibrant color schemes on light backgrounds

5. ❌ **Complex silhouettes with too many words** → Words don't fit well
   ✅ Use simpler shapes or reduce word count

## Optimization Tips

### For Best Quality
- Canvas Size: 1600x1200 or larger
- Max Words: 150-200
- Font Size Range: 15-150

### For Quick Generation
- Canvas Size: 800x600
- Max Words: 50-100
- Font Size Range: 20-80

### For Large Displays
- Canvas Size: 2000x2000
- Max Words: 300
- Font Size Range: 30-300

### For Social Media
- Canvas Size: 1080x1080 (Instagram)
- Canvas Size: 1200x630 (Facebook)
- Background: Use brand colors
- Color Scheme: High contrast
